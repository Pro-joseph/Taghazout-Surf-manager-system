# 🌊 Surf School Management System

Backend application built with **PHP (OOP)** using a custom **MVC architecture**.  
This project manages a surf school: users, students, lessons, and enrollments.

---

## 📖 Overview

The system allows:

- Admins to manage lessons and students
- Students to register and enroll in lessons
- Tracking of payments and participation

---

## 🧱 Tech Stack

- **PHP (OOP)**
- **MySQL**
- **MVC Architecture (custom)**
- **PDO (Database access)**

## ⚙️ Features

- Authentication system (Register / Login)
- Role-based access (`admin`, `student`)
- Student profile management
- Lesson creation and listing
- Enrollment system
- Payment status tracking
